# Data Analytics Project

## Overview

This project demonstrates an end-to-end **Data Analytics workflow**, starting from dataset loading and data cleaning in Python to SQL-based analysis, Power BI dashboard creation, and final project reporting.

The main objective of the project is to transform raw data into meaningful insights using Python, SQL, and Power BI.

### Project Workflow

**Raw Dataset → Python → EDA & Data Cleaning → SQL Analysis → Power BI Dashboard → Report → Presentation**

## Project Steps

### 1. Dataset Loading

The dataset was imported into Python using **Pandas**.

Initial checks were performed to understand the structure and quality of the dataset.

### 2. Exploratory Data Analysis (EDA)

EDA was performed to identify patterns, trends, relationships, and potential issues in the data.

Key activities included:

* Dataset overview
* Statistical analysis
* Missing-value analysis
* Duplicate-value analysis
* Distribution analysis
* Categorical analysis
* Visualization of important variables

### 3. Data Cleaning

The raw dataset was cleaned and prepared for further analysis.

The cleaning process included:

* Handling missing values
* Removing duplicate records
* Correcting data types
* Standardizing column values
* Handling inconsistent or invalid values
* Creating additional columns where required

### 4. SQL Analysis

The cleaned data was loaded into a relational database and analyzed using SQL.

SQL queries were used to answer important business questions using:

* `SELECT`
* `WHERE`
* `GROUP BY`
* `ORDER BY`
* `COUNT`
* `SUM`
* `AVG`
* `CASE`
* `JOIN`
* Aggregate functions
* Subqueries where required

The analysis focused on identifying key trends, distributions, and insights from the dataset.

### 5. Power BI Dashboard

The analyzed data was connected to **Power BI** to create an interactive dashboard.

The dashboard includes:

* KPI cards
* Charts and graphs
* Filters / slicers
* Category-wise analysis
* Trend analysis
* Comparative visualizations
* Key business insights

The dashboard was designed to make the results easy to understand and explore.

### 6. Project Report

A detailed project report was prepared to document the complete analytical process.

The report covers:

* Project objective
* Dataset description
* Tools used
* Data cleaning process
* EDA
* SQL analysis
* Power BI dashboard
* Key findings
* Final conclusions

### 7. Project Presentation

A PowerPoint presentation was created using **Gamma** to present the project in a simple and professional format.

The presentation summarizes:

* Problem statement
* Dataset
* Methodology
* Analysis
* Dashboard
* Key insights
* Conclusion

## How to Run

### Step 1: Clone the Repository

```bash
git clone <your-github-repository-url>
```

### Step 2: Open the Python Notebook

Open:

```text
python/EDA_and_Data_Cleaning.ipynb
```

Run the notebook to:

* Load the dataset
* Explore the data
* Perform EDA
* Clean the data
* Prepare the dataset for SQL analysis

### Step 3: Run SQL Queries

Import the cleaned dataset into **PostgreSQL, MySQL, or SQL Server**.

Open:

```text
sql/analysis_queries.sql
```

Run the queries to reproduce the analysis.

### Step 4: Open Power BI Dashboard

Open:

```text
powerbi/dashboard.pbix
```

Update the data source if required and refresh the dashboard.

### Step 5: View the Report & Presentation

The final project documentation and presentation are available in:

```text
report/
presentation/
```
